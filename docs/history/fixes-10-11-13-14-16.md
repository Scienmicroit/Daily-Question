# 第10、11、13、14、16项修复与回归

本轮只处理这五项，其他审查事项暂不扩展；版本号仍为2.0.0，未修改dist安装包，未打包或发布。

| 项目 | 结果与检查 |
| --- | --- |
| 10. 追问答案可信状态 | `tutor-status-check.mjs`：核验状态严格区分；空答案不冒充已校验；模型结果不称官方答案；检查实际传给模型的上下文 |
| 11. 判分绑定作答 | `attempt-binding-check.mjs`、`ui-race-check.mjs`：前后端传递并验证作答ID，双标签页各自判分，响应对应自己的记录，相同请求幂等，拒绝缺ID、串题及覆盖已判结果 |
| 13. 长列表性能 | `list-performance-check.mjs`：5000题/15000次作答，统计与查询只构建一次作答索引，默认50道分页；筛选、总量、页码边界及全栏目ID选择正确，数据更新后索引刷新；`render-check.mjs`及`ui-race-check.mjs`验证分页按钮、跨页全选、返回与跨日刷新不串页 |
| 14. 重复今日题的完成状态 | `daily-attempt-check.mjs`：按宿主练习日关联作答，昨天完成不解锁今天，今天完成后重启仍展示答案，下一天再次分配重新锁定，兼容旧格式时间戳并保留历史记录 |
| 16. 历史去重与覆盖 | `generation-history-check.mjs`：全历史精确重复、换排版/选项顺序/长题干换题型及近期近似题检查；较少题型和主题优先，过滤大纲行政章节与题型名称；独立检查覆盖匹配；历史答案不进入命题提示，盲解仍只有题干和选项；保存前再次检查并发历史，正式保存覆盖目标 |

检查命令：`npm test`，新增检查均已加入。使用临时数据、模型替身及合成材料，不调用付费模型，不使用正式学习数据。

本机合成数据测试中，5000道含较长题干的题目、15000次作答，统计及多次分页/筛选查询约40多毫秒，一次单文件原子保存约80毫秒；这是当前机器的单次测试，不能当作所有设备的性能保证。

边界：仍使用单文件JSON，未改造备份、多实例写入或数据库；超大数据量仍有全量保存成本。去重是全量归一化指纹与近期文本相似度判断；近似特征每题最多检查前2万字符，不保证识别全部语义重复。主题安排依据当前能辨认的大纲主题与近期频次，不等同于按官方整卷权重排题。本轮未进行真实浏览器、付费模型或所有科目的联网验收。
