# 自定义考试自主检索验收（2026-11-05）

## 实现与边界

自定义科目默认按名称及代码自主检索，不使用逐科固定来源。默认模型规划搜索，程序仅读取真实搜索结果及正文附件链接，另一独立调用核对考试身份、实际年份、大纲正文和至少两年真题。通过后接入原有命题、盲解、分歧主裁及独立难度校验。原有明确选择的内置参考考试保留原路径。

六位专业代码不能直接映射成三位考试科目代码；院校不明或自命题代码重号时需补充信息。转载大纲要求不同来源机构的同年正文交叉依据，不宣称官方原书逐字认证。扫描PDF没有可用文本层时仍可能失败。
