# 考研每日一题

面向 **DeepSeek Harness（DSH）** 的考研练习插件。按科目每天分配一道题，把作答、答案解析、收藏、错题整理和针对本题的追问放在同一个页面中。

当前版本：**2.0.0**。本插件需要 DSH 宿主，不是独立运行的网站或命令行应用。

## 2.0.0 更新

- 采用蓝色主题，正确与错误分别使用绿色、红色；统一科目管理、题库管理和确认弹窗的样式。
- 科目管理支持草稿：勾选科目、切换来源、添加自定义科目和题型后，点击右下角「完成」统一保存；取消或关闭不生效。
- 全部、收藏、错题本支持批量收藏、取消收藏、加入或移出错题本、删除，以及全选和全不选。
- 题目卡片最多预览两行，支持公式和代码；截断时在最后一行实际可见内容末端渐隐，不添加省略号。
- 点击整张卡片进入详情；独立的方形「‹」按钮返回原列表与滚动位置。
- 栏目栏固定在内容区左上方；重复点击当前栏目不重复请求。
- 追问默认收起，查看本次答案后才显示入口；宽屏支持拖动分隔线调整比例，收起后题目填满可用宽度。
- Enter 发送追问，Shift+Enter 换行；中文输入法确认候选词不会误发送。
- 修复保存失败后内存状态不回退、并发作答重复计数、自定义题型在线生成失效、题库过早重复出题，以及考试结束前提前切换年份等问题。

## 安装

### 环境要求

- 已安装并能运行的 DSH。
- Node.js **20.3.0 或更新版本**（由运行宿主的环境提供）。
- 在线出题、答案修订和追问需要宿主配置可用的默认模型。
- 公式引擎随包提供，无需单独下载字体或公式依赖。

### 安装本地安装包

仓库的 `dist/` 目录提供：

```text
dist/daily-question-2.0.0.tgz
```

在 DSH Desktop 的插件安装入口填写该文件的绝对路径。命令行使用与你运行宿主一致的 profile，例如：

```bash
dsh plugin --profile web add ./dist/daily-question-2.0.0.tgz
```

Desktop 管理的 `desktop` profile 请通过 Desktop 插件界面操作。安装完成后重启相应宿主或刷新客户端，左侧栏出现「考研每日一题」入口。

### 从 npm 安装

**维护者发布 2.0.0 后**，可以安装指定版本：

```bash
dsh plugin --profile web add daily-question@2.0.0
```

DSH Desktop 可在插件安装入口填写 `daily-question@2.0.0`。命令行安装还需满足宿主对包管理器的要求；若提示缺少 pnpm，先安装或启用 pnpm。

### 从 GitHub 或源码安装

发布 `v2.0.0` 标签后，可锁定该标签安装；此方式需要 Git：

```bash
dsh plugin --profile web add github:Scienmicroit/Daily-Question#v2.0.0
```

本地开发也可以直接安装源码目录：

```bash
dsh plugin --profile web add ./Daily-Question
```

升级时重新安装目标版本即可。卸载命令为：

```bash
dsh plugin --profile web remove daily-question
```

卸载插件不会自动删除保存在数据目录中的学习记录。

## 开始练习

1. 打开「科目管理」，选择需要练习的科目并设置出题来源，点击「完成」。关闭或取消弹窗会放弃尚未保存的修改。
2. 选择目标考研年份，核对倒计时与日期来源。
3. 在「今日题目」开始作答。在线出题包括生成和独立校验，首次加载可能需要几十秒。
4. 需要题库时，在「题库管理」导入文件，检查预览和解析提示，再确认入库。
5. 查看答案后，可收藏题目、整理错题，或打开「本题追问」继续讨论。

内置科目包括思想政治理论、英语一、英语二、数学一、数学二、数学三。自定义科目支持内置题型和自行命名的题型。

## 出题与作答规则

### 每日分配

每个启用科目每天分配一道固定题目。再次进入同一科目的今日题目会复用该日的分配；新的自然日按宿主本地日期计算。

| 来源 | 行为 |
| --- | --- |
| 在线出题 | 使用宿主默认模型生成，再进行独立视角校验 |
| 题库出题 | 从已导入且符合科目题型的题库中抽题 |
| 自动 | 优先题库，没有可用题目时尝试在线出题 |

题库优先使用未出过的题，新题用完后选择最久未出的题；只有少量可用题目时允许重复。删除已出题目不等于删除原题库，未来仍可能重新抽到该题。

在线出题与校验分两次模型调用完成。校验不通过时会带反馈重出，最多尝试两轮；仍不通过则不发布。独立校验仍由模型执行，不等同于官方审定。

### 判分与历史

- 选择题提交后按参考选项判分，并展示答案与解析。
- 主观题可选择「作答完毕」或「未能作答」。前者先记为待判定，查看答案后由用户判断正确或错误；后者记为错误。
- 打开题目不增加作答次数，提交并查看答案才记一次；同一作答 ID 的重复请求不会重复计数。
- 手动加入错题本不会生成一条虚假的错误作答记录；移出错题本也不会删除历史作答。

从列表打开历史题时，默认进入新一轮作答并隐藏答案。属于本科目今日题且已经查看答案时，默认保留已完成状态。主动点击「重新作答」会隐藏答案、解析和追问入口，直到本轮再次查看答案；同一页面会话内切换栏目再返回，也会保留这轮重新作答状态。

### 答案版本与追问

正式答案与解析保存为固定版本，重新打开不会再次生成。用户请求修订时，候选答案必须通过校验并经用户确认，才会替换正式版本；旧版保留在版本历史中。

追问按题目 ID 隔离，使用本题资料和该线程近期历史。生成失败会保留输入并支持重试；清空对话只影响当前题目。查看答案后才显示追问按钮，默认不自动展开面板。

宽屏下可拖动题目和追问之间的分隔线，或聚焦分隔线后用方向键调整；窄屏使用侧边浮层，不提供比例拖动。发送方式为 Enter，换行为 Shift+Enter。

## 列表与批量管理

今日题目、全部、收藏和错题本使用同一题目记录，各科目分别管理。

在「全部 / 收藏 / 错题本」点击「批量管理」后，可以逐题选择、全选或全不选，并执行：

- 收藏、取消收藏。
- 加入错题本、移出错题本。
- 永久删除所选题目。

删除题目会同时清理该题的作答、追问和今日分配引用。包含收藏或错题时，会在普通删除确认之后再要求一次确认。删除不可恢复。

停用科目或删除题库只会停止相应的后续分配，不会删除已出题目及其作答、收藏和追问；需要永久删除题目时使用列表的删除功能。

## 导入题库

支持 `.md`、`.txt` 和文本型 `.pdf`。扫描件或图片型 PDF 不提供 OCR；提取效果受 PDF 的字体、编码与排版影响，导入前必须核对预览。

建议按下面的结构组织 Markdown，以题号或分隔线区分题目：

```markdown
## 第 1 题
设函数 $f(x)=x^2$，求 $f'(1)$。

A. 1
B. 2
C. 3
D. 4

答案：B
解析：由 $f'(x)=2x$，得 $f'(1)=2$。
知识点：导数计算
难度：2

---

## 第 2 题
证明闭区间上连续函数的最值性质。

答案：闭区间上的连续函数能取得最大值和最小值。
解析：结合闭区间紧致性与连续函数的性质说明结论。
```

导入答案标记为「待核验」，缺少答案的题目标记为「缺少答案」。导入成功只表示解析完成，不代表参考答案已经验证。

## 公式、代码与日期

题干、选项、答案、解析和追问支持 Markdown，包括代码围栏、表格、图片、行内公式和独立公式。MathJax 3.2.2 使用 SVG 输出，随包提供；题目列表只预览前两行，完整内容进入详情查看。

公式基准字号固定，长公式可横向滚动，保留上下标和分式的正常排版比例。代码块保留缩进与换行。界面包含轻量动效，并尊重系统的「减少动态效果」设置。

考研年份使用入学年份口径，例如 **2028 考研对应 2027 年末的初试**。日期区分官方公布、估算和尚未核实；估算日期标注「约」。联网核验只采信教育部、研招网与教育考试院的指定官方域名。

倒计时第一行显示剩余总天数，中间一行按 **365 天为一年、30 天为一个月**拆分，并省略数值为零的单位，例如「1年23天」「3个月」「2年」；剩余不超过 30 天时隐藏中间一行。这一拆分是显示换算，不是自然月的日历差。

## 数据与隐私

学习数据使用本机单文件 JSON 保存。默认路径按以下顺序解析：

1. 设置了 `DSH_DAILY_QUESTION_DATA_DIR`：直接使用该目录。
2. 否则设置了 `DSH_PROFILE_DIR`：使用其下的 `daily-question/`。
3. 否则使用 `DSH_HOME/daily-question/`；未设置 `DSH_HOME` 时为用户主目录下的 `.dsh/daily-question/`。

数据文件名为 `data.json`。单个服务实例内串行更新，通过临时文件写入后替换正式文件；保存失败不会把未保存的修改提交到内存状态。不要让多个宿主进程同时写入同一份数据文件。升级前建议备份数据目录。

题库文件在本机解析；在线出题、答案修订和追问使用宿主配置的模型服务。题目或题库内容参与修订、追问时，相关资料会发送给该模型服务。Markdown 中的远程图片和用户主动打开的链接可能访问外部网站。公式渲染本身无需联网。

## 开发与验证

本项目使用原生 JavaScript ES Modules，没有独立的前端构建步骤。

```bash
npm test
node --check client.js
```

离线测试覆盖日期换算、题库解析、持久化、业务状态、并发作答、批量管理、科目草稿和渲染组件。不需要真实模型或联网；这些测试不能替代实际 DSH 宿主中的安装与模型联调。

可以额外使用自己的文本型 PDF 检查提取效果：

```bash
node test/pdf-check.mjs <PDF文件路径>
```

主要文件：

| 路径 | 用途 |
| --- | --- |
| `index.js` | 宿主入口与服务注册 |
| `client.js` | 页面、交互、Markdown 与公式渲染 |
| `lib/service.js` | 出题、作答、列表、题库与追问业务 |
| `lib/store.js` | 数据目录与原子持久化 |
| `lib/generate.js` | 模型出题、答案校验和修订 |
| `lib/bank.js`、`lib/pdf.js` | 题库解析与 PDF 文本提取 |
| `lib/exam-dates.js` | 日期来源、核验和倒计时 |
| `lib/routes.js` | 同源接口与 MathJax 静态资源 |
| `test/` | 离线回归检查 |
| `vendor/mathjax/` | 随包公式引擎及许可 |

## 维护者发布

修改版本号后先验证，再生成安装包：

```bash
npm test
npm pack --pack-destination dist
```

2.0.0 对应产物为 `dist/daily-question-2.0.0.tgz`。建议将确认过的安装包同时作为 GitHub Release 附件，并直接发布同一份文件到 npm：

```bash
npm login --registry=https://registry.npmjs.org/
npm whoami --registry=https://registry.npmjs.org/
npm publish ./dist/daily-question-2.0.0.tgz --access public --registry=https://registry.npmjs.org/
npm view daily-question@2.0.0 version --registry=https://registry.npmjs.org/
```

按 npm 提示完成浏览器登录与发布验证。发布账号需要拥有 `daily-question` 包的发布权限；若该版本已经发布，不可用相同版本号覆盖。GitHub 标签、npm 版本和安装包版本应保持一致。
