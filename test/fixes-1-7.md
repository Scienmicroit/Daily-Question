# 审查第1～7项修复与回归检查

本轮仅处理第1～7项，版本号、dist安装包以及后续问题保持原状，未打包或发布。

| 项目 | 回归检查 |
| --- | --- |
| 1. 无答案选择题误判 | `service-check.mjs`：无有效选项答案时记录pending，保留用户选项，不自动进错题本，支持人工判断 |
| 2. 旧请求覆盖新页面 | `ui-race-check.mjs`、`render-check.mjs`：栏目/开题/收藏/判分/修订/错题操作/追问/批量操作响应错序，不串页；清空后的网络旧回复不恢复内容 |
| 3. 追问恢复与去重 | `followup-check.mjs`：启动恢复pending、同消息并发只生成一次、成功幂等、失败原ID重试、清空失效旧回复 |
| 4. 超时与取消 | `task-check.mjs`、`ui-race-check.mjs`：模型不响应信号也能结束等待，三种任务总超时、手动取消、释放占用、立即重试、迟到结果不发布、卸载终止及界面取消入口 |
| 5. 漏选新版公告 | `research-check.mjs`：审查结果漏选已读新版公告仍阻止旧大纲；短公告保留；不误拦截其他院校的公告 |
| 6. PDF页序 | `pdf-safety-check.mjs`：对象编号与实际顺序相反、嵌套页树、间接Kids列表、循环引用及异步题库入口 |
| 7. PDF资源边界 | `pdf-safety-check.mjs`：压缩膨胀、过滤链、累计展开量、对象流/字体/页数/深度/文本限制，限制错误不被吞掉；生产默认8MiB上限；工作线程超时、取消、排队上限与恢复 |

检查命令：`npm test`。所有回归使用临时数据、合成PDF和模型替身，不调用付费模型，不访问正式学习数据。

尚未执行真实浏览器操作或真实模型完整联网验收；此次修复不表示第8项“自主检索完整联网验收”已经通过，也未增加扫描PDF的OCR能力。
